# Minimal GitHub Pages site

This is intentionally just two website files:

- `index.html` — page content
- `style.css` — appearance

## Test locally

Double-click `index.html`. It should open in your browser.

## Publish with GitHub Pages

1. Create a GitHub repository named exactly:

   `YOUR-GITHUB-USERNAME.github.io`

2. Upload `index.html` and `style.css` to the top level of that repository.

3. In the repository, open:

   `Settings → Pages`

4. Under **Build and deployment**, choose:

   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`

5. Save.

Your website will be available at:

`https://YOUR-GITHUB-USERNAME.github.io/`
