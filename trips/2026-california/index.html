路線簡介

East Buttress @ Mt. Whitney

Mt. Whitney 號稱 highest point in the lower 48，意思是美國除了Alaska與Hawaii之外的最高點（Hawaii沒有高山，所以其實就是Alaska外最高峰），也是美國第11高峰 [Wikipedia]. 最大眾的攀登方式是從 Whitney Portal 出發，經由 Mount Whitney Trail接上Mt. Whitney的南稜（這段也是John Muir Trail (JMT) 的最南段）登頂。這段步道因為難度較低，在非雪季時相當熱門，有有限的permit quota，需要透過lottery system取得。

除了Mount Whitney Trail外，另一條登頂路線是從North Fork of Lone Pine Creek Trail，一樣從Whitney Portal出發，直接抵達Mt. Whitney的東面山腳下的Iceberg Lake。到這邊之後有兩種選擇：一種是走Mountaineer's Route，經過北側的雪溝（在夏天冰雪會融化，剩下崩溝，成為3rd/4th class路線）登頂；第二種則是攀登任意一條5th class路線，其中最熱門的是East Buttress，一條11 pitches、5.7的alpine路線。通常攀登這條路線後，Mountaineer's Route則成為descent路線。

要攀登East Buttress，首先要驅車抵達Whitney Portal （~h2544m）。如果是fly in的話可以飛到LAX或LAS，兩者都是國際機場，到Portal的車程大約都是4.5小時。接著要hike in到Iceberg Lake （~h3850m）。大部分的人會選擇紮營在此，隔天一早開爬，但也有人選擇紮在較低的Upper Boy Scout Lake （~h3460m）。隔天先approach到路線起點（粗估~h4100m），然後攀登11個繩距登頂（h4421m）。descend的Mountaineer's Route分成兩段：從summit到"The Notch"、以及從The Notch到Iceberg Lake。The Notch是連接東面和西面的一個小凹槽，在the Notch之上有條路：一條下段是3rd class，上段是4th class（最後的400 feet常稱為Final 400'），最為陡峭。另一條 "Easy walkoff"，腰繞到更西邊、更緩的地方（見底下第四張圖）。

Snake Dike @ Half Dome

Yosemite Valley中，有兩顆石頭最為有名：一顆叫El Capitan （也就是Alex Honnald free solo的那顆），另一顆叫Half Dome。Half Dome的南面有一條攀岩界有名的路線叫Snake Dike，定級5.7 R ，R代表的是run out：路線共有8 pitches，其中P3到P6中分別有一部分的段落有R等級，例如P4約160' (48m) 中間只有一顆bolt（此段難度5.4）。歷史上大家不斷爭執是否要補更多bolt，一直沒有共識。一直到2026年6月，有人在付諸實行去retrobolted，卻引起軒然大波，Bolt也在一週內就被全部切除。此爭議背後的論點複雜，詳見兩則 original thread：ref1, ref2，以及我覺得挺公道的意見：1, 2, 3, 4, 5 （和OP的留言）（我也覺得這條其實應該是X-rated）。

要攀登這條路線，要從Yosemite Valley的Happy Isles，也就是JMT的最北端出發，中間接上Mist Trail經過Vernal Fall，再接回JMT，最後上切到一條climber's trail，直到到達Half Dome西南面的路線起點整段approach約3-5小時。經過8個pitches的5th class climbing後，接著是超過300m的3rd class slab，直到summit。

Descent則是經由大眾攀登Half Dome的路線（The Cables），沿著Half Dome東北面一排打在岩壁上的扶手下攀（從這邊上去好像也是個需要Lottery system的permit）。接著就是比來的時候更大一圈的步道，接上JMT、也就是approach的路。

Logistics and other miscellaneous information

Permit

進入 North Fork of Lone Pine Creek Trail 和在 Cathedral Lake 過夜都需要Wilderness permit，兩者都是透過 Recreation.gov 。兩者分別在加州時間的兩週和一週前07:00釋出，經測試發現實際的釋出時間提早了約37秒（也就是06:59:23，以 https://time.is/ 為準），這兩個都很難搶，如果在07:00才重新整理肯定搶不到。強烈建議在實際搶之前先在幾天前練習看看，熟悉系統操作。此外，這兩者我都沒有碰到CAPTCHA，有興趣的人可以參考關鍵字 ChromeDriver。

註：如果上Whitney並且從Trail Crest出來的話，有個另外的總額限制。如果要從那邊出來的話要在Permit type選Overnight exiting Mt. Whitney。

交通

Mt. Whitney距離LAX和LAS其實車程大約都是4.5小時，但因為我們都想順便去LA訪友，所以決定飛LAX然後在這邊租車。後來決定加入Yosemite行程，於是就安排了爬完Mt. Whitney後開車殺去Yosemite，最後一天再一路開6小時的車回LAX。

營地

Whitney Trailhead Campground

位在Whitney Portal的First-come-first-serve campground。其他campground都超難預約，所以除非超早開始規劃，這大概是一般人的唯一選擇。

  • 位置：往Portal開到底後繞一圈（那邊是單行道），車停在Portal的對面那側（南邊），campsites在路旁。上面這兩張牌子大概在這裡。
  • 預約：First-come-first-serve，出發前Reddit上都說我們星期六很晚上去不可能有位子，結果我們到了之後還有不少空位。這邊看起來是有規劃既定搭帳的位子（有一塊一塊整好的空地，但其實有的有一點點斜），但沒有編號什麼的。
  • 設施：有熊櫃，就在停車場，也有Vault toilet，沒看到水龍頭。沒有訊號。

Icerberg Lake (dispersed)

爬Mt. Whitney或Mt. Russel的自然營地選擇。

  • 位置：Iceberg Lake 南側 (36.58033, -118.28514)，有幾個明顯是整理過的搭帳地點，有用石頭堆的擋風牆。
  • 預約：不必
  • 設施：Dispersed camping，當然除了水之外啥都沒有，自備熊罐。排遺不可掩埋，要帶Wag bag打包出去丟（Portal有地方可以免費領，也有統一丟棄處）。水則是自備濾水器用湖水。當然沒有訊號（但Mt. Whitney山頂有）。

Cathedral Lake (dispersed)

因為Cathedral Peak上的Southeast Buttress是大熱門線，我們（參考YouTube上一些影片）決定前一晚先踢進來紮在Cathedral Lake湖邊。這晚紮在這的應該只有我們是攀岩的人，其他看起來有的是要走JMT的。

  • 位置：Upper Cathedral Lake周圍，我們紮在東側，有蠻多空地可以紮，但西側看起來也有不少人紮。
  • 預約：不必，但要在這邊過夜需要申請Wilderness permit （見Permit）然後不能紮離步道和水源太近（拿Permit的時候Ranger會跟你說）。
  • 設施：因為是Dispersed camping當然除了水之外啥都沒有，自備熊罐。排遺不必pack out，可以挖洞埋起來（Ranger會跟你說要挖多深，然後問你有沒有帶鏟子）。水則是自備濾水器用湖水。沒有收訊。

Tuolumne Meadows Backpacker Campground

營地入口

營地入口貼的規定

營地入口放的，包含一個小信封，讓人自己放錢/填付款資訊後丟到旁邊的箱子裡，以及一個tag放在紮營處

Yosemite的Backpacker campgrounds是讓有Wilderness permit的人在行程的前一晚和後一晚紮的，詳細規定見official page。在這邊的牌子寫說只給沒有車的人紮，但似乎是過時的規定，因為網站上沒寫，我們直接開車進去時，入口的管理員也就只說裡面沒有overnight parking，只能臨時停車load/unload。

  • 位置：Tuolumne Meadows Campground開到最裡面（大概在這）。營區入口處有個亭子，開進去的時候可以在那邊付錢，管理者會跟你說在哪。裡面有既定編號的紮營地點。
  • 預約：First-come-first-serve。
  • 停車：營區內沒有給Backpacker的overnight parking，管理者會跟你說你要在卸貨區卸貨後，停到營區外再走進來（最近的地方在Lembert Dome）。廁所旁有一個殘障車位和非殘障車位，那個非殘障車位沒有什麼特別標示，不知道可不可以停隔夜。
  • 設施：每個營地旁都有熊櫃，卸貨處有個有水的廁所。整個Tuolumne區域內都沒有訊號，包含Visitor Center。

Yosemite Valley Camp 4

大概是Valley內最climber-friendly的營地，沒有像是Upper Pines那麼難搶（但還是不好搶）。營區分成一塊一塊編號，每一塊大概會有三四頂帳，共用熊櫃和桌子。周圍有很多boulder，包含著名的Midnight Lightning。在裡面走來走去就會看到不少人在整裝或是背著crash pad。

  • 位置：Camp 4 Yosemite Valley。
  • 預約：一週前預約，through Rec.gov, see official page。即使是周間且有一百多個位子，依然會在釋出的幾秒內被搶光（但至少不是一秒之內），所以時間一定要算好。試圖寫程式操控的話會遇到CAPTCHA。
  • 停車：有共用的停車場，要有預約才能停，Check in的時候會給tag。
  • 設施：每個營地旁都有熊櫃，有個有水的廁所，有Wifi但是要在check in的亭子那邊才比較連得到，我們的營位的地方可以連到LTE（我用mint），勉強堪用。

Groceries and gas

除了出發時在LA的Walmart有採買外，在Whitney下來後我們也停了Bishop（路上唯一比較大的城鎮）的 Vons （Vons）。離開Tuolumne進到Valley內之後，Valley Store其實有不少生鮮的選擇（當然觀光區還是貴了一點但至少有不是罐頭的肉可以買，像是培根、絞肉或是一般的雞肉等等，也有不少蔬菜）。Camp 4對面的Valley Lodge （Yosemite Valley Lodge Gift Shop）也可以買到一些冷凍食品，但選擇少很多。

加州的油價是出名的貴。我們離開LA後，在上Whitney前補了一些油，不想加滿因為Lone Pine在觀光區的油比較貴。離開這邊之後、到Yosemite前，有一家加油站明顯比較便宜（Fort Independence Travel Plaza & Winnedumah Winns Casino）。Tioga Pass入口處也有加油站（Mobil）但超貴，進到Valley前也有加油站且意外的便宜（Crane Flat Gas Station - (24/7 Gas Pumps)）。當然，再怎麼樣還是比不上回到城鎮的Costco油價。

天氣

這區雖然為在地中海型氣候，但夏天的山區依然可以有很多thunderstorm。除了下雨讓岩壁溼滑的風險外，另一大風險來源是雷擊，在各個summit都有雷擊風險的相關告示。除了出發前查好天氣資訊外，若要在沒有訊號的區域（Whitney和Tuolumne）久待，可以尋求InReach的天氣預報（似乎一次$0.5），以及Wilderness Center和Visior Center也都有提供天氣資訊。

另外，在牆上只要沒曬到太陽，風還是可以吹得挺冷的，所以風雨衣記得要準備好 （偷偷推薦一下我覺得很滿意的風雨衣、長褲和內層）。

熊

注意！這次經過的所有區域都是會有熊出沒的區域，所有食物（以及任何有味道的物品，例如牙膏、防蚊液、防曬乳等）在晚上都必須放入熊櫃、或是熊罐（放置遠離帳篷），車上也要避免有食物的味道殘留（因此我們基本上在下山前都不外帶速食）。否則不僅會罰鍰，熊甚至會硬闖車子把車子砸爛。

GPS

（手機的）GPS和航跡在這趟旅程非常好用也非常重要，務必一定要準備。雖然大部分的地方都還是有路跡和疊石，但有時不明顯處容易跟丟，此時就需要花很多額外的時間和體力跟回路跡。換句話說，雖然熟悉勘查的人大概還是可以找到路，但是有GPS和航跡的指引下就可以省下大把的時間和體力。此外，美國的不到和在台灣的勘查有一點重要的不同，就是時常經過亂石堆、石板等，在這種地方就毫無路跡可言，只能依賴疊石，在沒有疊石的地方就是最容易跟丟步道的時候。在這種時候GPS航跡就非常有幫助。

這趟我準備地圖的做法是使用CalTopo，操作相當方便、且有可以直接使用的底圖和步道。如果要自製，USGS有公開的地圖（參見How to download maps from the USGS database: Mt. Whitney as an example），但我還沒有找到像魯地圖那樣方便、可以直接匯入使用的底圖（如果有人知道請告訴我）。CalTopo可以直接匯出GeoPDF，雖然畫質差了一些但還是相當堪用。

我的手機是Pixel 10，在加州的一週內都開Extreme battery saver，續航力超乎我想像地久，電充滿可以撐三天以上，完全不需要使用行動電源，靠開車時充電即可。我使用的App是 OruxMaps，在新版Android有些麻煩之處，詳見Using offline maps in OruxMaps。

心得

HC

首先，必須先感謝幫忙接下留守的PC、被PC諮詢而提供許多實用資訊的D、以及老姐借的熊罐與濾水器。最重要的是再次陪我受苦受難的繩伴PH，目前在美國內除了PH之外，應該還沒有第二個人是我敢一起爬這種路線的人。

這趟旅程hike in、hike out之類走路的時間很多，不免就開始想東想西。如今攀岩第六年，一開始甚至是因為登山社不收才開始攀岩，對於傳攀從陌生到恐懼、一直到自己有了一套熟悉且完整的double rack才開始習慣、到最近半年多才逐漸開始建立在牆上的一點自信，不會每次上牆都在擔心會不會爬不完、裝備收不下來。從去年年底在J-Tree和這趟在Whitney上，好像終於開始有種在牆上放開來享受的感覺。緊張的部分肯定還是有的，但似乎多了一股難以壓抑的興奮。

第一次聽說Mt. Whitney其實是因為我姐抽到了Permit要去爬，那時想說只是踢踢步道就沒特別感興趣（實際上他們去的時間是初夏，還有不少雪，也不是踢踢步道那麼簡單）。過了一陣子突然在instagram上滑到了別人爬East Buttress的影片，突然就被影片中的風景吸引了。簡單Google了一下發現難度是5.7 11 pitches，單就攀爬難度來說我知道應該不是太大的問題，但是因為是alpine climbing，路線長（在此之前我在美國爬過最長的路線應該是在Red Rocks的Dark Shadows （5.8 4 pitches））、又在偏遠的山區，心知一點都沒有那麼簡單，於是就先tag了PH給他看看有沒有搞頭。

The comment that sparked the trip.

在美國攀岩有PH作伴是無比幸運的事情。也許我因為身高手長，在許多動作上相對於他佔了不少優勢，但以傳攀經驗、或是in general戶外經驗而論我是遠不如他。我在經驗不足之下，在岩場的決策時常沒有自信，此時PH總是可以給出穩重的決定。例如因為PH，準備Cathedral Peak複雜的descent時，我對於我們在牆上臨機應變的能力比我自己一個人更有自信許多。此外，PH是我在傳攀路線上，那位「爬不完不用擔心，他會上去幫我收下來」的人物之一（前年Red Rocks就發生過，有興趣可以回去翻紀錄）。這次也是傳了影片跟他討論之後他也覺得有搞頭才開始安排的，否則我肯定是看看影片就算了XD。在後面幾天，他更是在感冒以及Mt. Whitney的疲憊之下，硬扛著跟我一起爬完Snake Dike，我既是愧疚又是感激。

Yosemite的部分其實我一開始是不感興趣的，因為最有名的El Cap沒有big wall能力的我是不可能爬的。PH提了之後我才上去翻了一下Mountain Project，看到Cathedral Peak路線的岩塔（一直到認真準備路線才知道那張不是真正的Cathedral Peak，而是隔壁的Eichorn Pinnacle）和DAFF Dome，都是從來沒爬過的地形，不由自主地也引起了一點興趣。Snake Dike也是PH提的，一開始我看到那個R就先卻步了，完全不感興趣。一直到過了一陣子Snake Dike drama發生，我才同意如果bolt到我們出發還沒被切掉的話也許可以試試。在準備過程中看了很多影片，終究也是被爬上Half Dome的想法吸引了。只不過在YouTube上GoPro視角下，很難看出實際上有多陡、多刺激。雖然bolt在不到一個禮拜就被切掉了，慢慢開始出現「幾十年來聽說只有一起嚴重的意外，5.7我應該可以吧？」的想法。就這樣Snake Dike也被加入目標清單中了。

雖說East Buttress定級只有5.7，hike in的重裝爬升1,300m也不是開玩笑的。考慮到我也很多年沒有負重爬山了，出發前一個月來是拿出了大學在山社時的體訓標準來練練。可惜我所在的小城沒有什麼高樓可以負重（身為一個沒在上健身房的人，突然要我背著30kg的背包去健身房踩那個爬樓梯的機器實在太羞恥了），只好跑步。所幸心肺耐力似乎沒有太大的退步，也就祈禱不會負重後就直接「破功」了。實際在hike in的時候，雖然還是挺喘的，但因為沿路從來沒親眼見過的冰河地形，感覺上遠不如預期中痛苦。從Lower Boy Scout Lake附近岩石和植被交雜、接近Upper Boy Scout的石板溪流與滑瀑、爬上Iceberg Lake前的U型谷、與Iceberg Lake本身，不得不說在我心目中擠下了所有在台灣爬過的山（但我在爬過的山其實也不算多就是了）。下山時，雖然沿路都是上山時看過的景觀，但搭配日出又是不同的感覺，看著風景踢著踢著就回到Portal了。

在攀登East Buttress路線本身時，因為擔心遇到thunderstorm、以及對於當天踢下山還沒死心，所以一路上分成兩種狀態：在PH爬的時候就看風景、拍照、休息、和看好下一段leading的topo，輪到我攀爬時就專心一步接著一步的做，先鋒時為了加速也刻意多run out一些（好在難度不高所以不會太害怕）。雖然有些急，但在被後面那組超車之後也就沒啥壓力。雖然到後面的幾個pitch知道當天下山是無望了，但至少攀爬過程很流暢、在牆上沒有待太久。不過，下次如果再爬類似難度的路線，也許我會考慮增加simul的比例來增加效率。這次爬完確實也感覺路線有一大部分是可以simul的，但我一直到lead完P8才意識到剩下的路線應該可以simul，然後才發現我其實simul的經驗很少，只會最基本的操作，上次收kiwi coil都忘了是什麼時候了。下次爬這種低難度、保護可靠的路線時，應該要更熟悉simul的操作（我事後偶然看到這些影片，和這篇Brent的文章，也許可以參考）。

Mountaineer's Route的descent大概是整趟下來，對我來說最痛苦的一段了。因為我對這類2nd/3rd class （甚至還不到4th class！）scrambling實在是經驗很少，一路下來連懷疑人生的機會都沒有，沿路都在繃緊神經地踩著每一步、心想這步要是滑了就是直接滑到山腳下了。看著走在前面的PH好像絲毫沒有緊張的感覺、又想到昨天上山時遇到day hike的人們，實在是無法理解他們難道都不會害怕嗎？以前在學先鋒攀登、練習克服fear of falling時，學到了fight-or-flight response，感覺以後如果遇到這類的3rd class甚至4th class scrambling（特別是碎石坡），大概會更害怕，也許以後不會再對這類的alpine路線感興趣？但誰知道呢，就像PH所說，也許過了一段時間又被新路線吸引了也說不定，哈。

Cathedral Peak上的Southeast Buttress又是個完全不同的體驗。因為出發前看的預報，在開爬時我腦中一直想著需要和天氣賽跑，越快下來越好降低遇上thunderstorm的風險。結果就是攀爬時緊繃又慌張，到了預定的anchor處時士氣已經少了大半，又遇上下雨，想想繼續往上的風險實在太大了，就成了我的第一次長路線撤退經驗。要是再來一次，我想我們早上一樣會選擇出發、下雨一樣會選擇撤退。雖然沒爬到到完整的路線很失望，但我想我們都同意當下做的決策是正確的，一點都不覺得後悔，只能怨Tuolumne （tu-O-lou-me！）的天氣變幻莫測。一來累積了一次撤退的經驗、二來也留下了再來的理由。

Snake Dike又是個全新的體驗。雖然在攀登過程中不能失手的時機也不是沒有經歷過，但 run out 20光用想的還是令人手心冒汗。在這趟之前我在花崗岩的friction slab經驗其實挺不錯的，但一切都在Cathedral Lake的慌亂下被摧毀了。在Cathedral Lake hike out的幾個小時我不斷地懷疑自己，連5.6都緊張成那樣了，Snake Dike的5.7真的可以嗎？但仔細一想發現我已經是as ready as I ever will be，感覺再怎麼爬對於5.7 slab的信心似乎也就是那樣，剛剛似乎是因為慌張而沒有辦法靜下心來好好找到每一步的動作。在踢出trailhead時就說服自己，只要靜下心來、一步一步找好動作，應該是沒問題的。為了避免重蹈覆徹、自信被P1 trad摧毀，我很不要臉地問了PH能不能接下P1和P2，好在他很爽快地答應了。所幸到了P2 anchor，發現P3的第一顆bolt遠不如想像中的遠、傾度也沒有想像中的那麼可怕、bolt後面的crux看起來也就是兩步，看看覺得應該沒問題就上了。Dike就和預期中的一樣，雖然run out非常遠，但就不要往下看，看著眼前的手腳點、確保每一步都可以穩定、有自信地做到，其實很快就結束了。爬完後，其實我也可以理解（"I don't condone, I understand!"）反對增加bolt的理由（這是條有歷史的路線，且只要小心地爬，其實fall在run out pitches的機會真的不大），但我依然希望可以在P1 alt-start、P3-6都可以補上幾顆bolt，來增加未來攀爬者的安全性。優質的路線不該被gatekeeping，應該是大家共享的。

如今回到家已經兩週了，看著照片，Yosemite Valley的美景和Whitney Area險峻的群峰依舊是歷歷在目。我對於alpine climb有著兩難的心情：一方面嚮往山中的美景、在岩壁上攀岩者獨享的自由，一方面也害怕任何3rd/4th class scrambling。也許短時間內很難再說服自己踏出下一步，但難保未來不會看到新的路線，又被大自然所誘惑。如同John Muir所說："The mountains are calling and I must go."

最後是給技術組成員/學員的一段話：這次爬的兩條路線看上去也許很酷，實際上也沒啥了不起的。就是兩條5.7、攀登難度其實很低，我們用上的技巧絕大多數在中岩也都有教（我忘了simul是在中岩還是雪訓教的了），所以就技術層面來說，大家都有足夠的知識來爬。然而事情當然也沒那麼單純：alpine climbing因為地處偏遠、救援困難、岩質脆弱（這次的兩條都很熱門，比較沒這個問題）、天氣變化快，相對一般的傳攀需要更有效率、更有把握。光是會爬多繩距是不夠的，想爬酷路線還是需要有一定的攀登能力，有把握把路線順順地爬完、不take/fall。至於攀爬效率，除了run out之外，其實有很多部分是在中岩練習的（請不要在中岩隨便run out…），例如減少起攀時準備的時間、以及swing leads的時候的輪轉時間（例如，當我follow完到anchor，就趕緊交換裝備、喝口水、快速瞄一眼topo就接著爬了，see here, and more pro tips here.）。

PH

遙想當初在大學時期開始接觸攀岩技術時，就是為了克服一些爬山時所遇到的困難地形落差，例如開繩確保崩壁或是垂直斷崖，如今隨著攀岩經驗技術慢慢累積，發現原來攀岩也是一種親近一座山的方式，還能看到只屬於攀岩者的美景。

大概是三、四月時，看完 Instagram 上 Cody 的 Whitney alpine climbing 影片後就心癢癢的。無瑕姣好的花崗岩面，加上攀岩者身後的高山湖泊，我想任何喜歡多繩距、又喜歡看風景的人大概都很難抗拒。儘管上次 Longs Peak The Diamond 的經歷痛苦萬分，心裡還是有點懷念那種待在高山岩壁上的奔放感受。於是 HC和我就開始計畫這次從 East Buttress 上 Mt. Whitney 的路線。晚夏的Mt. Whitney比較平易近人，只要單純對付岩石就好，無須對付冰雪岩等複雜狀況。當然我們不可能大老遠飛去加州為了只爬這個，想想也不知道在美國還能待多久，於是就順道安排Yosemite的行程。

出發前我就認知到approch對我來說會是一大難關，很久沒上高山再加上本身負重能力就不算突出，儘管行前努力調整身體狀況維持了約一個月zone 2 和負重訓練，但在高山上的表現還是不盡理想，在Upper Boyscout Lake附近明顯的感受到身體疲倦與無力，很久沒有動用到意志力邁出下一步，咬牙默數著呼吸配合步伐往上推進，有點回到剛開始大學時期剛接觸高山的感覺，但差別在於背包因為攀岩裝備更重爬升也更多，好險HC有分掉一點裝備陪我慢慢往前，我們原本還妄想著可以早點到營地去看看隔天的approch。靠近Iceberg Lake時，Crook、Keeler、Whitney 山脊突然迫近在眼前，崢嶸聳峻的群峰連線總讓我想到南美洲Patagonia的照片，這是台灣的高山和之前去過幾座Colorado 14er不曾帶給我的震撼，像一排巨人的下排尖牙陳列在眼前，我們只是循著比較緩、山稜線的脆弱部分進行攀登，難以想像攀爬其他陡峻岩壁部分，只能瞻仰。

隔日一早，跟在其他隊伍後面來到起攀，第一個pitch其實我就感覺到比想像中吃力一點，一方面是有點久沒trad climbing，二方面是身體沒有非常習慣高海拔劇烈運動，感覺運動能力像超商即期食品一樣被打了75折，每一次放保護點和入繩動作都感覺比平時在山下要勞累，爬完後的收繩直接榨乾手臂僅存的一絲力氣，之後的第三第四pitch 雖然很run out但好險動作都簡單，我反而覺得整趟下來第一pitch時感受上最難，到第六pitch時好像已經對長距離run out已麻木，放的保護點感覺都只是裝飾用或是引導跟攀者用，說實話保護點和確保站我也沒有很認真去完善，放到70/100分我就覺得可以接受，不想多花時間再調整只為求快，安全、能用、不要浪費時間就好，第九pitch之後再加上一些奇怪的simul後稀里糊塗地就登頂了，比起peak帶來的喜悅，我更喜歡看著Iceberg Lake在腳下慢慢越來越小，另外還記得在第七第八pitch跟攀時，我當時在想HC到底怎麼敢lead這兩個莫名其妙的pitch，我明明也看了guidebook但有看沒有懂，瞬間理解走哪究竟需要多強的洞察力，另外他哪來的勇氣毅然決然地挑戰煙囪over地形？

隔日下山，腳已經不是自己的了，沒有一塊腿部肌肉是不感到痠痛的，而且開始有一些感冒症狀出現，接著轉往 Yosemite，當時的下一個目標是 Cathedral Peak (我叫牠Cat Peak)，Cat Peak是個長的很有意思的山峰，「橫看成嶺側成峰、遠近高低各不同」的描述非常適合，我個人覺得它像一隻貓有兩個尖耳，又或者是蝙蝠俠的頭，雖然因為下雨撤退沒能爬上牠的頭頂上看看，但光是Cat lake (Cathedral Lake)跟Cat peak的風景就很值得走進來，完完全全不覺得撤退有什麼損失，除開攀岩未竟的部分就是一個五星級湖邊露營體驗，隨後，出登山口天氣就放晴了，如果說扼腕肯定是有的，但當下已經做了最理性、最適切的決策，一切都是運氣。

再隔了一天，感冒更嚴重了，感覺腳步虛浮、頭暈、畏寒，雖然不到很嚴重，但絕對不是一個適合攀岩健行的身體狀態，這天取消了West Crack計畫，早早就到Yosemite像一般觀光客晃晃，老實說我個人對行程取消完全不感到可惜，雖然有點對不起HC，看得出他很有力很想爬，但這天的休息對我來說太重要了，如果這天還爬就等同於沒有休息天去挑戰最後的大魔王Snake Dike我大概會直接陣亡，事後來看是個正確的決策，當晚Camp 4 非常難睡，半夜聊天聲、小孩尖叫打鬧聲、車流聲讓我們難以早早入睡。

隔天一早三點起床，儘管不到狀態絕佳但比前一天好非常多了，走到岩壁下才知道內傾角度跟影片和照片感覺很不一樣，剛開始第一個pitch就被狠狠教訓了一番，一直以來都很不擅長friction slab，尤其是放完第一個保護後run out的時候，心境過於不鎮定，完全無法感知到自己腳下踩的到底紮不紮實，狼狽地爬到第二pitch難關時還發現cam size不對心態又再崩潰一次，後面rope drag過大還不小心手滑差點在no fall zone裡掉了，回想起第一次去squamish 爬friction也是這麼狼狽，扣到第二pitch anchor感覺心已經死了一半，有種腎上腺素用太多後的虛脫感，老實說我太小看前兩個pitch了，好險第三pitch friction難關是HC lead 我可以不用面對，繩伴是slab 達人根本賺爛。

後面輪到我的第四和第六pitch都是爬突起的dike，事後想想大概40米的路線只有一個bolt真的是有點瘋狂，好險都不算難就是小腿會很痠痛，我很喜歡HC在這裡的pep talk:「專注在眼前的動作，anchor就會不知不覺地來到眼前了」，儘管在爬之前很多內外在因素充斥著 : 口乾舌燥、風很大、沒有遮蔽很曬、所有下肢肌肉都在發痛、bolt 到底在哪怎麼那麼少那麼遠、anchor在哪我會不會不小心錯過了、挖靠這裡失手可能會死耶之類的心裡murmur...，在抓住dike上那些不規則突起後上述的一切都被拋在腦後了，身體被肌肉記憶引導、自動地找到向上的最佳解答，不知不覺終點就在眼前，就像在岩館裡橫渡一樣，低強度高專注度的一種心流狀態。後面第七pitch friction slab又再次出現，我又再次慶幸不是輪到我lead，跪著看HC上演恐怖的謎之信仰friction 攀爬，明明guidebook寫在右邊但他硬生生走上了虛無飄渺的光滑左面...，我只能讚嘆他心理素質強悍，第八pitch其實不難但既然有保護可放實在是不想再run out了，但岩械不夠只好拆成兩半爬，後面就是燃燒小腿肌的slab地獄一路到Half Dome頂。

Half Dome的頂峰剛好可以幾乎把Yosemite全貌盡收眼底，望向Tuolumne Meadow方向才發現Yosemite真的好美，突然可以理解為什麼那麼多攀岩大神願意長年待在這裡，心裡想著未來有機會肯定要再來一次，純攀岩或健行都好，隨後就是漫長的回程，經歷15小時的攀岩和健行，我已經想不起來究竟是怎麼榨出最後一點力氣把晚餐煮完，再把食物送進胃裡的，只記得那晚是七天以來睡的最舒服的一晚。

回到Virginia兩周在此寫完心得，如果這時候問我要不要再爬一次alpine或是類似的多繩距，我會毫不猶豫地斷然回絕，但我沒有自信這個答案在半年後、一年後是不變的，Grand Teton、RMNP、又或者是未竟的Cat Peak，美國自然景觀誘惑實在太多了，最後要謝謝好繩伴HC，總是lead完我不敢lead的pitch、可憐的被我傳染感冒、分掉我背包的裝備還等我上坡，雖然我還是沒有很懂晚餐喝湯的美好，但每次都會偷學到一點新東西，例如 : 煮angel hair非常快又省瓦斯，期待下次美國約爬，不過alpine先真的暫時不要。

How to download maps from the USGS database: Mt. Whitney as an example

  • Downloaded from the USGS database. It's probably easiest to download GeoPDF files, which can be either printed out, or imported into mobile GPS apps like OruxMaps.
  • Instructions to use USGS database:
  • Go to USGS database, open the National Map Downloader, and find the trail in the map first.
  • On the top left, use any of the tools, e.g., "Extent", under "Area of interest" to select the extent of the map needed, such as the whole trail.
  • For GeoPDF, go to "Map", check "US Topo". In the subcategories, choose "US Topo current", which are the currently maintained maps.
  • For data extent, choose "7.5 x 7.5 minute" (1 minute = 1/60 degree in latitude/longitude). For file formats, choose "Geospatial PDF". Both of which are actually the only options.
  • Under "Advanced search", click "Search Product".
  • The available maps will then show up. The two maps that cover Mt. Whitney trails are "Mount Langley, CA" and "Mount Whitney, CA".
  • Click "Download Link (PDF)" to download.
  • See Using offline maps in OruxMaps for tutorials on how to put this map in OruxMaps.

Using offline maps in OruxMaps

Here, I document the steps to import geoPDFs (and possibly other formats) into OruxMaps. This is extremely useful for route finding. The GeoPDF can come from the USGS database, as described above, downloaded from CalTopo, or other custom sources.

I struggled a bit with this because there seems to be a bug in the setting of OruxMaps when selecting the folder that contains the maps, and Android 14 or newer there are some permission BS that makes it difficult to access the default directory where the app searches for the maps. One of the workarounds is to use ADB (android debug bridge). Here I document the steps that work for me.

  1. Save the downloaded PDF files in your phone internal storage, anywhere you can find it.
  2. In OruxMaps, go to settings (the gear icon inside the list on the top left), go to "App Storage". Under "Directories", look for "Maps directory". This is the default directory to put the GeoPDF files you just downloaded. Unfortunately, this is most likely under ~/Android/data/. On newer OS, permission to access this directory is banned.
  3. You can try the option "Alternative maps directory" just underneath. Try selecting a folder you can access in your phone. The detailed steps depend on the OS, but for me I couldn't select any accessible folder due to some BS about permission and an apparent bug. My only resolution is then to access the default directory with ADB.
  4. Install ADB on your PC (E.g., for macOS, see here).
  5. Enable ADB on your phone (It is under developer options. Detailed instructions depend on the phone), and connect it to the PC. Run "adb devices" from your CLI. If everything works out, you should see a message saying that ADB has started.
  6. As described here, run "adb shell". You now have access to the shell, and you can use the standard Linux commands (e.g., cd, mv, ls) to move the downloaded GeoPDF files to the default directory. As a side note, if you record a GPX, you would the same method to move the exported files to a readable directory too.
  7. OruxMaps can now find those files. Go back to the main menu (where you can see the maps). Tap the maps icon to go to the page where you can select map layers.
  8. Your map should now show up under the "offline" tab. You can then select them. Unfortunately it seems that you can only show one map at a time.
  9. If you have internet access, you can also go to the "Online" tab. Under "Layers -> (US)" you can find "USGS Topo (US)", which also seems to be useful.
